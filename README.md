# Run Locally

Install dependencies (once, and after pulling changes that touch `package.json`):

```
npm install
```

Start the dev server with hot reload:

```
npm run dev
```

Produce a static production bundle in `dist/`:

```
npm run build
```

Serve the built bundle locally to sanity-check it:

```
npm run preview
```
